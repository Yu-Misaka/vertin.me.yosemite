# 动效重编排方案

记录日期：2026-10-28。用户已确认此方向并授权实施。

## 设计原则

框架稳定、内容连贯、操作轻快，进入阅读后安静下来。

- 左侧头像、导航和播放器作为空间参照，导航期间保持位置与播放状态。
- 页面切换只编排主要内容和发生变化的右侧模块。同一时刻只有一个页面过渡。
- 同一篇文章的列表封面与详情封面衔接，作为网站的主要标志动作。
- 内容不因动画改变布局高度；正文、公式、代码不逐段入场。
- 返回位置、锚点、交互响应优先于动画。动画可取消，不能排队阻塞导航。

## 场景与节奏

| 场景 | 编排 | 基准 |
| --- | --- | --- |
| 首次打开 | 框架直接呈现，首屏最多三级内容淡入并上移 8px | 280ms，错开 35ms |
| 普通导航 | 内容交叠淡出与淡入，位移 8px；辅助模块单独淡入 | 220ms |
| 列表进入文章 | 可见且加载完成的同篇封面衔接，正文整体淡入 | 封面 300ms，正文 180ms |
| 列表封面悬停 | 轻放大至 1.015；点击时保留当前裁切，封面衔接后平滑复原 | 悬停与复原 450ms，柔和起步 |
| 标题装饰条 | 主题色渐变粗线按标题宽度适度变化，默认 72–120px，悬停或键盘聚焦延长至 96–160px 并稍加深 | 220ms，移开后收回 |
| 返回列表 | 由 Astro 恢复滚动位置，仅在两端封面可见时衔接 | 位置恢复优先 |
| 分页 | 下一页从右侧 12px 进入，上一页反向 | 220ms |
| 控件反馈 | 颜色、背景、边框变化；小控件按下缩至 0.98 | 120–160ms |
| 回顶控件 | 出现保持轻快，消失时先淡出，再隐藏 | 出现 160ms，淡出 280ms |
| 折叠与 Tabs | 高度调整与内容淡入同步，可连续切换 | 220ms / 180ms |
| 主题 | 配色同步变化，图标轻转；不与页面快照竞争 | 200ms |
| 目录 | 短距离指示条跟随，长距离直接定位 | 160ms |
| 通知 | 8px 短距离浮现，不从屏幕外横穿 | 180ms |

## 工程约束

- 保留 Astro ClientRouter 为唯一导航与快照所有者，不增加第二套路由或动画框架。
- CSS 时长、缓动、距离统一使用 motion.css 中的令牌；组件使用这些令牌。
- WAAPI 仅用于首屏、局部状态变化；结束与取消都释放 effect。
- 只共享封面，不共享正文、标题或整张长文章卡片。
- 深链接、评论锚点、未加载或不可见的封面使用普通过渡。
- 原有图片缩放关闭后再捕获页面；主题切换可跳过正在播放的页面过渡。
- 减少动态效果时跳过动画并禁用平滑滚动；不支持原生快照时立即换页。
- 默认内容可见，不依赖 JavaScript 或 animationend 才能显示正文。
- 图片、字体和布局变化后重新测量导航、目录和局部控件。

## 验收

- 首次打开、普通导航、列表与详情、分页、无封面文章、评论锚点。
- 连续快速导航、返回与前进、返回列表的滚动位置、深滚动文章。
- Tabs 点击与键盘、折叠连续开关、图片或字体晚加载。
- 明暗主题、导航时切换主题、图片放大后导航、播放器跨页状态。
- 手机布局、无横向溢出、触控反馈、减少动态效果。
- 项目类型检查、现有测试、生产构建和产物校验通过。

## 实施记录

### 已实现

- 将组件原有的分散时长、缓动收敛到 motion.css；首屏最多三级入场，普通导航、横向分页、目录与封面分别编排。
- 主内容快照保留离场时的视口位置，关闭整个长文档边界的自动插值，避免列表深滚动后进入文章时整页大幅移动。只有封面执行几何衔接。
- 匹配两端的封面暂时使用 Astro persistence 复用已解码图片，避免新文档的图片加载状态让共享动画失效。结束、取消、降级均清除临时属性。
- 共享封面只在两端可见、同篇、同图且没有目标锚点时启用。准备期间继续滚动会重新检查，历史滚动恢复后再次检查目标。
- 左侧框架与右侧搜索、分类、标签持久保留，目录独立更新。修复持久导航在文章、分页中的选中状态。
- 左侧导航的当前页面灰框固定保留，直接绘制在带 aria-current="page" 的链接上，不再依赖负层级伪元素。鼠标悬停或键盘聚焦其他项时，在该项独立显示一个更浅的灰框，只做背景变化，移开后淡出。移除浮动指示器及位置测量，触屏不保留悬停状态。
- 导航选中项优先匹配真实 URL，仅在非菜单页面使用声明的父页面。服务器首次渲染即提供 aria-current；每次 after-swap 和 page-load 都重新同步持久导航，包括重复加载同一个页面根节点。
- Tabs 支持整块内容淡入、可取消的高度变化与键盘导航；折叠使用实际测量高度，并随图片、字体或内容尺寸变化重新测量。
- 删除折叠短代码的旧内联 max-height，同时兼容已有编译内容，避免新高度动画仍被限制为零。
- 去除交互中的字距、字重变化和友链整体放大；头像简化为单层光环，小控件按下幅度收敛至 0.98。
- 主题切换取消旧页面快照，通知改为 8px 短距离浮现，图片缩放在导航捕获前关闭。
- 初始化提前到 after-swap 并保持幂等；开发热更新也会释放旧监听器，避免重复初始化。

### Tabs 底部间距连续性修正（2026-10-30）

- CV 切换到 Contact 时，段落的底部外边距在自然高度下折叠到 tabs 容器外；播放固定高度动画时，这段外部间距消失，动画结束后又恢复。Chrome 逐帧实测友链会先越过最终位置 24px，再跳回；起始帧也会丢失原时间线的 28px 外部间距。
