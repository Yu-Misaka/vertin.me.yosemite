## Project Overview

Personal blog built with Astro 7 and the "PureSuck" theme. Content is in Chinese. The Astro project lives inside the `site/` directory.

## Commands

All commands run from the `site/` directory:

```bash
cd site
npm run dev        # Dev server at localhost:4321
npm run build      # Build static site + Pagefind search index (postbuild)
npm run preview    # Preview production build
npx astro sync     # Sync content collection types
npx tsc --noEmit   # TypeScript check (used in CI)
```

## Architecture

**Content Collections** (`site/src/content/`): Two Zod-validated collections — `posts` (blog entries) and `pages` (standalone pages). Posts use frontmatter fields: `title`, `date`, `tags`, `category`, `cover`, `draft`, etc. Pages merge into navigation via `order` field.

**Routing**: Astro static generation with `getStaticPaths()`. Key dynamic routes:
- `posts/[slug].astro` — individual posts
- `[slug].astro` — standalone pages
- `page/[page].astro`, `tags/[tag].astro`, `categories/[category].astro` — listing pages

**Site Config** (`site/src/config/site.ts`): Central configuration for title, navigation, pagination, comments (Twikoo), music (APlayer), theme color, and feature toggles. Theme color tokens are in `site/src/config/theme.ts` (9 color options with light/dark variants; the site uses `brass`).

**Markdown Pipeline**: remark GFM + remark-math, followed by build-time shortcode compilation/image metadata in `src/rehype/rehype-content.mjs`, rehype-katex and table wrapping. Preserve the legacy shortcode syntax and code examples. Never reintroduce whole-body client-side parsing.

**Client-side JS** (`site/src/scripts/`): `app.js` owns page lifecycle. Feature modules accept AbortSignal and release their observers/listeners/pending work. Search, image zoom and APlayer load as separate chunks. Twikoo 2 is loaded once as an unchanged hashed local UMD asset; its injected styles persist in the layout style host. Its Vue 3 app is unmounted on navigation, and the bundled `zh-CN` locale matches the site language. Static assets and theme styles are bundled by Vite. Font CSS is generated by the Vite plugin in `src/integrations/fonts.mjs` from the original font shards and current source/content.

**View Transitions**: Astro ClientRouter owns navigation snapshots and scroll restoration, with cover-only shared elements when both endpoints are visible and loaded. The header and static sidebar utilities persist; the article TOC transitions independently. `styles/motion.css` owns motion tokens; `scripts/animations.js` coordinates ordinary navigation, directional pagination, cancellation and local reveal helpers. Never hide article content or collapse layout for snapshots. WAAPI is limited to visible cards on first load and local widget/theme effects, all released on completion or abort. Reduced-motion users skip animations; unsupported browsers use an immediate swap. See `docs/motion-design.md` for the accepted design and validation record.

**Search**: Pagefind generates a static search index during postbuild. Content is marked with `data-pagefind-body` and `data-pagefind-meta` attributes.

## CI

GitHub Actions (`.github/workflows/ci.yml`): Node 24, runs `npm ci` → `astro sync` → `tsc --noEmit` → `npm test` → `npm run build` → `npm run verify:build` from `site/`.
